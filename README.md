# Carreira Em Foco

Crie um site moderno, profissional, responsivo e visualmente atrativo para um projeto acadêmico de uma faculdade.

🎯 Objetivo do projeto

O site deve funcionar como uma plataforma para ajudar estudantes e pessoas que estão entrando no mercado de trabalho a encontrar informações e ferramentas úteis para sua vida profissional.

A plataforma deve reunir principalmente:

📄 Orientações para criação de currículo;

🎓 Cursos gratuitos e cursos com certificado;

💼 Oportunidades de emprego e estágio;

📚 Materiais e dicas para estudantes;

👤 Sistema de cadastro e login;

🔐 Área pessoal do usuário.

🏠 Página inicial

Criar uma página inicial moderna com um destaque principal contendo uma frase semelhante a:

"Construa seu futuro profissional."

Subtexto:

"Encontre cursos, aprenda a criar seu currículo e descubra oportunidades para dar os primeiros passos na sua carreira."

Adicionar dois botões principais:

[CRIAR MEU CURRÍCULO]

[ENCONTRAR CURSOS]

Adicionar também cards apresentando as principais funcionalidades:

📄 Currículos
"Aprenda a criar um currículo profissional mesmo sem experiência."

🎓 Cursos
"Encontre cursos gratuitos e opções com certificado."

💼 Oportunidades
"Encontre oportunidades de emprego, estágio e desenvolvimento profissional."

📚 Conteúdos
"Confira dicas e materiais para melhorar sua preparação profissional."

👤 Cadastro e Login

Criar uma área de autenticação com:

Nome completo;

E-mail;

Senha;

Confirmar senha;

Botão "Criar conta";

Botão "Entrar";

Opção "Esqueci minha senha".

Depois do cadastro, o usuário deve possuir uma área pessoal.

🧑‍💻 Área do usuário

Criar um painel onde o usuário possa visualizar:

Seu nome;

Perfil;

Cursos salvos;

Oportunidades salvas;

Currículo;

Progresso nos conteúdos.

Adicionar uma opção para editar o perfil.

📄 Página "Currículo"

Criar uma página explicando de maneira simples como fazer um bom currículo.

Organizar em etapas:

Dados pessoais;

Objetivo profissional;

Formação acadêmica;

Experiência profissional;

Cursos e certificados;

Habilidades;

Informações adicionais.

Adicionar um botão:

[CRIAR MEU CURRÍCULO]

Se possível, criar futuramente um gerador de currículo no próprio site, onde o usuário preenche seus dados e o sistema monta um modelo de currículo organizado.

🎓 Página "Cursos"

Criar uma página com cards de cursos.

Cada card deve apresentar:

Nome do curso;

Instituição;

Categoria;

Duração;

Informação sobre certificado;

Botão "Ver curso".

Adicionar filtros por categoria, por exemplo:

Tecnologia;

Administração;

Direito;

Marketing;

Finanças;

Idiomas;

Desenvolvimento pessoal.

Também adicionar uma barra de pesquisa:

"🔎 Pesquisar cursos..."

💼 Página "Oportunidades"

Criar uma página para apresentar:

Vagas de emprego;

Estágios;

Programas de aprendizagem;

Concursos;

Outras oportunidades profissionais.

Cada oportunidade deve possuir:

Título;

Empresa/instituição;

Localização;

Tipo de oportunidade;

Requisitos;

Prazo;

Botão "Ver oportunidade".

📚 Página "Conteúdos"

Criar uma área com artigos e dicas sobre:

Como conseguir o primeiro emprego;

Como fazer um bom currículo;

Como se preparar para uma entrevista;

Como encontrar cursos gratuitos;

Como conseguir estágio;

Como desenvolver habilidades profissionais.

🔎 Pesquisa

Adicionar uma barra de pesquisa no site para que o usuário consiga encontrar rapidamente:

Cursos;

Oportunidades;

Conteúdos;

Materiais.

🎨 Design

O site deve ter aparência de uma plataforma profissional, mas simples e fácil de utilizar.

Utilizar:

Design moderno;

Interface limpa;

Cards com bordas arredondadas;

Ícones;

Animações leves;

Boa hierarquia visual;

Espaçamento adequado;

Tipografia moderna;

Botões destacados;

Layout responsivo para celular, tablet e computador.

Evitar um visual exageradamente corporativo. O público principal são estudantes e jovens procurando oportunidades profissionais.

📱 Responsividade

O site deve funcionar perfeitamente em:

Computadores;

Notebooks;

Tablets;

Celulares.

Criar menu responsivo para telas pequenas.

🔍 SEO

Preparar o site para mecanismos de busca como o Google.

Utilizar títulos, descrições e textos relevantes relacionados a:

cursos gratuitos;

cursos com certificado;

como fazer currículo;

modelo de currículo;

oportunidades de emprego;

estágio;

desenvolvimento profissional.

Criar uma estrutura HTML semântica e boas práticas de SEO.

🌐 Publicação

O projeto deve ser desenvolvido de forma que possa ser publicado gratuitamente utilizando uma plataforma como Vercel ou GitHub Pages.

Não utilizar recursos pagos obrigatórios.

🎓 Contexto acadêmico

O site será apresentado como um projeto de faculdade.

Por isso, criar também uma página:

"Sobre o Projeto"

Nessa página apresentar:

Objetivo;

Problema identificado;

Solução proposta;

Público-alvo;

Benefícios da plataforma;

Equipe responsável.

⚠️ Importante

O site deve parecer um projeto real e funcional, e não apenas uma página demonstrativa.

Criar uma estrutura preparada para futuramente receber banco de dados, autenticação real, cadastro de usuários, cursos e oportunidades.

Utilizar componentes reutilizáveis e manter o código organizado.

Priorizar uma experiência simples:

Entrar → Encontrar informação → Cadastrar → Utilizar a plataforma.
